\section{Contexto}\label{contexto}

TODO: Explicar en qué contexto específico se han recolectado los datos y

El presente proyecto tiene como objetivo la creación de un dataset a
partir de datos extraídos de la plataforma Steam, una de las principales
tiendas digitales de videojuegos a nivel mundial.

Steam constituye una fuente pertinente para este proyecto porque ofrece
información pública y estructurada sobre videojuegos, incluyendo datos
como nombre del juego, desarrollador, editor, fecha de lanzamiento,
número de reseñas, descripción y etiquetas. Esta información es
ampliamente utilizada por usuarios y desarrolladores para analizar
tendencias del mercado.

Además, el sitio seleccionado cumple con los requisitos del enunciado,
ya que permite realizar scraping sobre múltiples páginas mediante
navegación automática, sin depender de una única tabla estática.

Los datos se han obtenido directamente de la web oficial de Steam:

\url{https://store.steampowered.com/}

El dataset generado recoge información de videojuegos disponibles en
Steam mediante un proceso automatizado de scraping desarrollado en
Python con Scrapy. Cada fila representa un videojuego individual,

\section{Código}\label{cuxf3digo}

TODO: Comentar los aspectos más relevantes del código, dificultades y
soluciones.

El proceso de recolección de datos se ha implementado utilizando Scrapy
en Python.

El sistema se compone de dos spiders:

LinksSpider: Se encarga de recorrer las páginas de búsqueda de Steam y
extraer los enlaces a videojuegos. Implementa paginación automática para
descubrir múltiples páginas.

AppsSpider: Utiliza las URLs obtenidas para acceder a cada página
individual y extraer los datos del dataset mediante selectores CSS.

Dificultades encontradas:

\begin{itemize}
\tightlist
\item
  Variabilidad en la estructura HTML\\
\item
  Páginas con restricción de edad (agecheck)\\
\item
  Valores faltantes\\
\item
  Diferencias de formato en números
\end{itemize}

Soluciones aplicadas:

\begin{itemize}
\tightlist
\item
  Validación de datos antes de procesarlos\\
\item
  Limpieza de datos\\
\item
  Filtrado de registros vacíos\\
\item
  Uso de selectores robustos
\end{itemize}
